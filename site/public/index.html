Workbench

A window on Claude Code or Pi.

The window is on Windows. The agent, your code and your terminals are in WSL.

01

In it

  • The scratchpadask something from Home, with no repo needed
  • Codespacesa folder in WSL with its files, an editor, terminals, and the agent beside them
  • Pull requests and ticketsyours on Home, and each one in a tab of its own, through dova
02

Get it

  • Run itworkbench.maxjay.dev/workbench.exe. One file. Nothing is installed.
  • Install itworkbench.maxjay.dev/workbench-setup.exe. Adds it to the Start menu. No admin needed.

Needs Windows 10 or 11 with WSL, and Claude Code or Pi installed in it. Pull requests and tickets need dova too.

Neither file is signed yet, so Windows may warn about it. Choose More info, then Run anyway.
